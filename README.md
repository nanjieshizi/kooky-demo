# Kooky Web Demo

这是 Kooky 的纯网页演示版本，保留当前网页端的视觉、mock 数据和演示交互，不包含 Electron 桌面端、安装脚本和打包配置。

在“协作”空间点击“新建群聊”，可打开“创建项目底座”弹窗，体验项目定位、边界、约束、成员与发布前检查流程。

## 启动

```bash
npm install
npm run dev
```

打开：<http://127.0.0.1:5173/super-assistant/>

## 构建

```bash
npm run build
```

该目录用于网页演示；完整桌面应用仍保留在同级的 `kooky-pata` 文件夹中。
